# Public Shadow evaluations

Maintainer: abgyjaguo. GPL-3.0-only.

The generated current score projection contains 217 assets. Immutable historical observations and verified on-demand screening results remain distinguishable by source publication. Recommendations use the existing category-relative top-quartile policy; this is research material, not endorsement or investment advice. Pending or rejected requests never produce scores.

Verify with `python scripts/verify_public_evaluations.py`. Regenerate on the trusted controller with `python scripts/refresh_on_demand_evaluations.py --config <authority-config>`. No private payloads, candidate code or credentials are published.

GPT-6 Sol / medium results are retained in `model-cohorts/gpt-6-sol-medium.json` for maintainer review. They are a separate model cohort and are excluded from current rankings and recommendations.
